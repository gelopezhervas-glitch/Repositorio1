# Laboratorio 2.1.5 - Introducción a Microsoft Excel
1. Además de Excel, ¿cuáles son otras tres aplicaciones que están disponibles de forma gratuita con una cuenta de Office.com?
   Microsoft Word, Microsoft PowerPoint y Microsoft Outlook, también OneNote y OneDrive.

2. ¿Qué sucede si escribe las coordenadas de una celda directamente en el Cuadro de Nombre de Celda?
   Excel selecciona inmediatamente esa celda específica y la convierte en la celda activa.

3. ¿Cómo puede seleccionar más de una columna o fila?
   Arrastrando el mouse sobre los encabezados de forma continua, o manteniendo presionada la tecla Ctrl mientras haces clic en varias celdas/columnas individuales.

4. ¿Cuál es el resultado de escribir `A1:C5` en el Cuadro Nombre de Celda?
   Se selecciona todo el rango rectangular de celdas desde la celda A1 hasta la C5, con A1 como la celda activa.

5. ¿Qué sucede con los datos en una hoja de trabajo cuando se elimina?
   Se borran de forma permanente y no se pueden recuperar con la acción de deshacer común a menos que el archivo tenga un historial de versiones en la nube.

6. ¿Qué métodos abreviados de teclado se utilizan para poner en negrita, cursiva y subrayar el contenido de la celda?
   Negrita: `Ctrl + B` o `Ctrl + N` en español
   Cursiva: `Ctrl + I` o `Ctrl + K` en español
   Subrayado: `Ctrl + U` o `Ctrl + S` en español
